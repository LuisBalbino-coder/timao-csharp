O que dá para fazer com C#

A mesma linguagem atende do script de dez linhas ao sistema de milhões de usuários. Estes são os caminhos reais.

Jogos de videogame

Unity (a engine mais usada do mundo) programa em C#. Também dá para usar Godot com C#, MonoGame (sucessor do XNA), Stride e FNA. No Unity você faz 2D, 3D, mobile, console e PC — inclusive build para Linux.

Web, APIs e back-end

ASP.NET Core é um dos frameworks web mais rápidos que existem. Com ele se fazem APIs REST, GraphQL, WebSockets, sistemas bancários, e-commerce e back-office. Blazor permite escrever a interface também em C#, rodando no navegador via WebAssembly.

Aplicativos de desktop

Avalonia e WPF para janelas no Windows/Linux/macOS, WinForms para sistemas internos, e .NET MAUI para um mesmo app rodar no desktop e no celular. Ótimo para ferramentas de empresa.

Automação e ferramentas

Scripts que renomeiam arquivos, geram relatórios em Excel, consomem APIs e rodam de madrugada no cron. O PowerShell é construído sobre .NET, então o que você aprende aqui vale lá também.

Nuvem e serviços

Azure Functions, AWS Lambda e workers rodam C# como serviço sob demanda. Filas, agendadores, integrações entre sistemas e processamento de arquivos são o pão de cada dia.

Dados, IA e IoT

ML.NET e ONNX Runtime executam modelos de IA em C#; Spark .NET processa grandes volumes; .NET nanoFramework e Raspberry Pi levam C# a sensores e placas. E sim, dá para controlar LED com C#.

Projeto final

Monte a tabela do Brasileirão

Junte tudo: classe Time, List<Time>, LINQ, exceções e JSON.

  1. Crie a classe com nome, pontos, jogos e saldo de gols.
  2. Ordene por pontos e, no empate, por saldo.
  3. Imprima a tabela com posição, nome, pontos e saldo.
  4. Salve o resultado em tabela.json e leia de volta ao abrir.
  5. Trate arquivo inexistente e JSON corrompido com try/catch.

Dica de corinthiano: coloque o Timão no topo da lista inicial, mas ordene de verdade — o código não tem coração.

class Time
{
    public string Nome  { get; set; } = "";
    public int    Pontos { get; set; }
    public int    Jogos  { get; set; }
    public int    Saldo  { get; set; }
}

var tabela = new List<Time>
{
    new() { Nome = "Corinthians", Pontos = 61, Jogos = 30, Saldo = 18 },
    new() { Nome = "Palmeiras",   Pontos = 58, Jogos = 30, Saldo = 22 },
    // ... complete com os outros
};

var ordenada = tabela
    .OrderByDescending(t => t.Pontos)
    .ThenByDescending(t => t.Saldo);

Dúvidas de quem está começando

Dá para aprender C# "100%"?

A linguagem inteira, em detalhe, é coisa de anos — mas este site cobre tudo que se usa de verdade no dia a dia, dos fundamentos ao async, banco de dados e testes. O que sobra é consulta na documentação, como faz todo profissional.

Quanto tempo leva?

Um módulo por dia, com o quiz no fim: fundamentos em pouco mais de duas semanas. As trilhas aplicadas levam mais uma semana cada uma.

Onde escrevo o código?

Instale o .NET SDK e o VS Code com a extensão C#. Crie o projeto com dotnet new console e rode com dotnet run. No Linux Mint funciona igual ao Windows.

Preciso saber matemática ou lógica antes?

Não. Os quatro primeiros módulos ensinam o essencial de lógica. Se travar, reescreva o exemplo digitando em vez de copiar.
