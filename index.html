01

Olá, Timão — seu primeiro programa

Saída no console · estrutura de um programa

Todo programa em C# vive dentro de uma classe e começa no método Main. A partir do C# 9 você pode escrever isso em poucas linhas (top-level statements), que é o formato dos exemplos aqui.

// Programa.cs
Console.WriteLine("Vai, Timão!");
Console.WriteLine("Aprender C# é igual subir a Vila: no começo cansa.");

int gols = 3;
Console.WriteLine($"Placar: Corinthians {gols} x 0");
  • Console.WriteLine escreve uma linha no terminal.
  • O $ antes das aspas liga a interpolação: {gols} é substituído pelo valor da variável.
  • Cada instrução termina em ; — esquecer o ponto e vírgula é o erro nº 1 de quem começa.

Para rodar de verdade: instale o .NET SDK, crie um projeto com dotnet new console -o Timao e execute dotnet run dentro da pasta.

02

Variáveis e tipos — a ficha do jogador

int, string, double, bool, var

Cada informação tem um tipo. Em C# você declara o tipo (ou usa var quando o compilador consegue deduzir).

string nome     = "Yuri Alberto";   // texto
int    camisa   = 9;                // inteiro
double altura   = 1.82;             // decimal (ponto, não vírgula)
bool   titular  = true;             // verdadeiro/falso
var    gols     = 17;               // o compilador deduz int

Console.WriteLine($"{nome} ({camisa}) tem {altura}m e {gols} gols.");
  • int = números inteiros; double e decimal = com casas decimais.
  • string sempre entre aspas duplas; char entre aspas simples.
  • var não é "sem tipo": o tipo é definido na primeira atribuição e não muda.
  • Em C# o separador decimal é ponto. 1,82 não compila.

03

Condições — vitória, empate ou derrota

if / else · operadores · switch

Programa é decisão. Com if você escolhe um caminho conforme uma condição booleana.

int corinthians = 2;
int adversario  = 1;

if (corinthians > adversario)
{
    Console.WriteLine("Vitória! Três pontos no bolso.");
}
else if (corinthians == adversario)
{
    Console.WriteLine("Empate. Um ponto e muita reclamação da arbitragem.");
}
else
{
    Console.WriteLine("Derrota. Semana de silêncio no grupo.");
}

// switch é bom para várias opções fixas
char resultado = 'V';

switch (resultado)
{
    case 'V': Console.WriteLine("3 pontos"); break;
    case 'E': Console.WriteLine("1 ponto");  break;
    case 'D': Console.WriteLine("0 ponto");  break;
    default:  Console.WriteLine("Rodada não jogada"); break;
}
  • Comparação de igualdade é == (dois iguais). Um só é atribuição.
  • Operadores lógicos: && (e), || (ou), ! (não).
  • Use else if em cadeia em vez de if dentro de if — fica mais legível.

04

Repetição — escalando os 11

for · while · foreach

Quando algo se repete, você usa laço. for serve quando sabe quantas vezes; foreach percorre coleções; while repete enquanto a condição for verdadeira.

string[] escalacao =
{
    "Hugo Souza", "Fagner", "Gil", "Cássio", "Fábio Santos",
    "Roni", "Renato Augusto", "Rodrigo Garro",
    "Yuri Alberto", "Róger Guedes", "Gustavo Mosquito"
};

// for com contador: ideal para "1 a 11"
for (int i = 0; i < escalacao.Length; i++)
{
    Console.WriteLine($"{i + 1}. {escalacao[i]}");
}

// foreach: mais legível quando você só quer cada item
int titulares = 0;
foreach (string jogador in escalacao)
{
    titulares++;
}

Console.WriteLine($"Total de titulares: {titulares}");
  • Arrays e listas começam no índice 0 — o primeiro jogador é escalacao[0].
  • escalacao.Length evita estourar o índice; nunca escreva i <= Length.
  • break sai do laço; continue pula para a próxima volta.

05

Métodos — reaproveitando o trabalho

parâmetros · retorno · sobrecarga

Método é um bloco com nome que recebe dados (parâmetros) e devolve um resultado (retorno). Serve para não repetir cálculo — e para dar nome à regra do jogo.

int Aproveitamento(int pontos, int jogos)
{
    if (jogos == 0) return 0;
    return pontos * 100 / (jogos * 3);   // % dos pontos possíveis
}

string Situacao(int aproveitamento) => aproveitamento switch
{
    >= 70 => "brigando pelo título",
    >= 45 => "no meio da tabela",
    _       => "brigando embaixo"
};

int pontos = 61;
int jogos  = 30;
int aprov   = Aproveitamento(pontos, jogos);

Console.WriteLine($"Aproveitamento: {aprov}% — {Situacao(aprov)}");
  • return encerra o método e entrega o valor. Métodos sem retorno usam void.
  • A forma => (expression-bodied) é atalho para métodos de uma linha só.
  • _ no switch é o caso padrão (o "qualquer outro valor").

06

Classes e objetos — o jogador é uma classe

propriedades · construtor · métodos de instância

Classe é o molde; objeto é cada jogador concreto criado a partir dele. Isso é a base da orientação a objetos — e o que você vai usar todo dia.

class Jogador
{
    public string Nome   { get; set; }
    public int    Camisa { get; set; }
    public int    Gols   { get; set; }

    // construtor: roda quando você faz new Jogador(...)
    public Jogador(string nome, int camisa)
    {
        Nome   = nome;
        Camisa = camisa;
        Gols   = 0;
    }

    public void MarcarGol() => Gols++;

    public string Resumo() => $"#{Camisa} {Nome} — {Gols} gols";
}

var garro = new Jogador("Rodrigo Garro", 10);
garro.MarcarGol();
garro.MarcarGol();

Console.WriteLine(garro.Resumo());
  • { get; set; } é uma propriedade — acesso controlado a um valor.
  • O construtor tem o mesmo nome da classe e não declara tipo de retorno.
  • Cada new cria um objeto independente: os gols do Garro não afetam os de outro jogador.

07

Listas e coleções — o elenco inteiro

List<T> · Add · Count · Sort

Array tem tamanho fixo. Para elenco que cresce na janela de transferências, use List<T>.

var elenco = new List<Jogador>
{
    new Jogador("Yuri Alberto", 9)  { Gols = 17 },
    new Jogador("Rodrigo Garro", 10) { Gols = 12 },
    new Jogador("Róger Guedes", 11)  { Gols = 15 }
};

elenco.Add(new Jogador("Memphis", 94));

int totalGols = 0;
foreach (var j in elenco)
{
    totalGols += j.Gols;
}

Console.WriteLine($"Elenco: {elenco.Count} jogadores, {totalGols} gols.");
Console.WriteLine($"Média: {(double)totalGols / elenco.Count:F1} gols por jogador.");
  • List<Jogador> só aceita objetos do tipo Jogador — o compilador garante isso.
  • Count é o tamanho da lista (em array é Length).
  • {(double)...:F1} formata com uma casa decimal; o cast evita divisão inteira.

08

LINQ — consultas de campeonato

Where · OrderBy · Select · Sum

LINQ transforma "percorrer e filtrar" em uma frase legível. É o recurso que mais impressiona quem vem de outra linguagem.

var artilheiros = elenco
    .Where(j => j.Gols >= 12)
    .OrderByDescending(j => j.Gols)
    .Select(j => $"{j.Nome}: {j.Gols}")
    .ToList();

foreach (var linha in artilheiros)
    Console.WriteLine(linha);

int golsDoTime = elenco.Sum(j => j.Gols);
var camisa10   = elenco.FirstOrDefault(j => j.Camisa == 10);

Console.WriteLine($"Total do time: {golsDoTime}");
Console.WriteLine(camisa10 is null ? "Sem camisa 10!" : camisa10.Nome);
  • => dentro de LINQ é uma lambda: "para cada jogador j, faça isto".
  • Where filtra, OrderBy ordena, Select transforma, Sum soma.
  • FirstOrDefault devolve null se não achar — sempre trate esse caso.
  • Precisa de using System.Linq; em projetos com using explícito.
